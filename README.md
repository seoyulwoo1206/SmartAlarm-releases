# SmartAlarm 설치 파일

수면 리듬을 보고 얕은 잠일 때 깨워 주는 개인용 안드로이드 알람 앱의 설치 파일(APK)만 올려 두는 곳이에요.

## 설치 방법
1. 오른쪽(폰에서는 아래쪽) **Releases**에서 가장 위에 있는 버전을 열어요.
2. **SmartAlarm.apk**를 눌러 내려받아요.
3. 폰의 **내 파일 → 다운로드**에서 열어 설치해요. Play 프로텍트가 막으면 "무시하고 설치하기".
4. 덮어 설치해도 알람과 수면 기록은 그대로 남아요.

최신 버전 바로 가기: https://github.com/seoyulwoo1206/SmartAlarm-releases/releases/latest
